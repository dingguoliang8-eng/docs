## 技术栈（与代表项目一致）

<CardGroup cols={2}>
  <Card title="智控台前端" icon="desktop">
    **Vue** 管理台，多环境 API，权限相关交互。
  </Card>

  <Card title="智控台后端" icon="server">
    **Java / Spring Boot**，MySQL，Redis；设备、智能体、模型、知识库、团队权限。
  </Card>

  <Card title="设备侧服务" icon="microchip">
    **Python / asyncio**，WebSocket 会话；VAD→ASR→LLM→TTS 或端到端语音。
  </Card>

  <Card title="检索与多模态" icon="database">
    向量检索（如 **Qdrant**）、Embedding 服务；ASR/TTS、视觉相关能力。
  </Card>
</CardGroup>

抽象模式与原理仍在知识库章节，不在此重复虚构「独立三件套产品」。
