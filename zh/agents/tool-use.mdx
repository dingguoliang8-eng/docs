工具把 LLM 从「只会写字」变成**能动手的系统**。没有工具，Agent 可以推理、规划，但改不了外部世界；有了工具，就能搜网页、跑代码、调 API、读写文件、查库——都在同一条推理循环里完成。背后机制是 **Function Calling**：模型吐出结构化 JSON（调哪个工具、参数是什么），你的代码执行，结果再作为下一次观察写回上下文。

---

## 一次工具调用怎么走完

四步：

1. **注册 Schema** — 初始化 LLM 时声明可用工具（名字、描述、参数）
2. **模型决策** — 决定调工具，发出 `tool_calls`（可同时带或不带文本）
3. **执行** — 你的代码拦截调用、跑对应函数、拿到输出
4. **回灌结果** — 包成 `ToolMessage` 追加到历史，成为下一次观察

```python agents/tool_lifecycle.py
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, ToolMessage
from langchain_core.tools import tool

@tool
def add_numbers(a: float, b: float) -> float:
    """Add two numbers together and return the sum."""
    return a + b

llm = ChatOpenAI(model="gpt-4o", temperature=0)
llm_with_tools = llm.bind_tools([add_numbers])

messages = [HumanMessage(content="What is 1337 + 42?")]
response = llm_with_tools.invoke(messages)

print(response.tool_calls)
# [{'name': 'add_numbers', 'args': {'a': 1337.0, 'b': 42.0}, 'id': 'call_abc123'}]

tool_call = response.tool_calls[0]
result = add_numbers.invoke(tool_call["args"])

messages += [response, ToolMessage(content=str(result), tool_call_id=tool_call["id"])]
final = llm_with_tools.invoke(messages)
print(final.content)  # "1337 + 42 = 1379"
```

<Note>
  模型从不直接执行代码——它只是**请求**执行。是否执行、怎么执行，永远由你的应用代码决定。所以才能用人工审批把危险操作拦住。
</Note>

## 怎么定义工具

LangChain 的 `@tool` 最省事：根据类型注解和 docstring 自动生成模型看到的 JSON Schema。

<Tip>
  **docstring 就是给模型看的说明。** 写清楚做什么、什么时候用、返回什么。含糊描述会导致乱调或过度调用。
</Tip>

常见类别：

- **信息获取**：网页搜索、向量库、只读 SQL
- **代码执行**：Python REPL、受控 shell
- **外部 API**：REST、Slack 等通知

## 错误处理

工具会失败：超时、500、路径不存在、SQL 写错。稳健的 Agent 要对每种失败有策略：

- 瞬时错误：重试（如 tenacity）
- 主通道挂了：换备用提供商
- 在图里：用 `ToolNode(handle_tool_errors=True)` 把异常变成错误 `ToolMessage`，让模型自己决定重试、换工具还是告诉用户做不了

<Tip>
  失败时优先返回**可读的错误字符串**，而不是把堆栈砸给模型。模型把错误当观察，才更容易自救。
</Tip>

## 并行工具调用

GPT-4o、Claude 等可以在**一次响应里发多个 tool call**。LangGraph 的 `ToolNode` 会并行执行，缩短多工具步骤的延迟。

模型一般只在判定调用彼此独立时才会并行。依赖关系写清楚（工具描述里说明），通常不必手写调度。

```python agents/tools/parallel_tools.py
from langgraph.prebuilt import ToolNode
from langchain_openai import ChatOpenAI

tools = [get_stock_price, get_company_news]
tool_node = ToolNode(tools)  # 自动并行
llm = ChatOpenAI(model="gpt-4o", temperature=0).bind_tools(tools)
```

---

## 小结

可靠工具使用 = 清晰 Schema \+ 可控执行 \+ 可恢复错误 \+（需要时）并行。把危险操作放在你能审批、能审计的路径上，比「让模型自己跑一切」更接近生产。
