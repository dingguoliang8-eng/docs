## 简介

我是一名 **AI 应用工程师**。日常工作在「模型能力」和「能上线的软件」之间：把大模型、检索和 Agent 流程接到真实产品里，而不是停在 Demo。

当前重点是把 AI 应用工程往 **Agent 系统工程** 推进；更远期的目标是 **AI Runtime Engineer**——理解 Agent 跑在什么执行环境之上。这个站点用来记下我怎么想这些问题、做过什么、还在学什么。

---

## 工程之路

路径是一步步走过来的：

```text
Java 后端开发
  → AI 应用工程
    → Agent 系统工程
      → AI Runtime Engineer（长期目标）
```

最早做 **Java 后端**，天天打交道的是可靠性、认证、权限和系统架构。这些习惯现在还在：做 AI 不能只盯模型和框架，租户隔离、访问控制和生产约束一样重要。

进入 **AI 应用工程** 后，更多是在已有 AI 平台上搭应用、把助手产品改造成可运营的 **SaaS**，并设计 **多租户** 结构。

接下来希望深入 **Agent 系统**：能规划、会调工具、能走多步任务的系统，而不是只会答一轮问题。再往后，会往 **AI Runtime** 走——Agent 依赖的执行环境与基础设施。

## 工程经验

做过和正在做的包括：

## 工程理念

**生产优先于 Demo。** 关心的是能运营、能加固、能演进的系统，不是 notebook 里好看的原型。

**先弄清架构，再谈框架。** 框架能加速交付，但检索、推理、租户隔离和失败路径要心里有数。

**AI 能力要配上靠谱的软件工程。** 认证、权限、多租户和系统架构是产品工作的一部分。

**把学到的写下来。** 这个知识库就是为了把判断、取舍和没想清楚的问题沉淀成可修订的文档。
