## Introduction

I am **Ding Guoliang**, an **AI Application Engineer**. I work between model capabilities and shippable software — wiring LLMs, retrieval, speech pipelines, and agent-style flows into products that hold up beyond demos.

Over the past half year and more, I helped build and close the loop on an **edge voice-agent control platform** (admin console \+ configuration/business API \+ on-device speech service). The product is functionally closed and entering production launch. My near-term focus is deepening into **Agent System Engineering**; longer term, **AI Runtime Engineering**.

This site records how I think about these systems, what trade-offs showed up in real work, and what I am still learning.

## Engineering Journey

```text
Java Backend Development
  → AI Application Engineering
    → Agent System Engineering
      → AI Runtime Engineer (long-term goal)
```

I started in **Java backend** work — reliability, auth, permissions, and system architecture. That still shapes how I approach AI: models matter, but so do tenancy, access control, and production constraints.

As an **AI Application Engineer**, I have worked on platform applications, turning assistant capabilities into operable products, and designing **multi-tenant / team permission** models with configuration delivery. On the device side, that means real-time speech sessions: VAD → ASR → LLM → TTS (and end-to-end speech paths), coordinated with tool calling and knowledge retrieval.

Next I want to go deeper into **agent systems** that plan, use tools, and run multi-step work — then into **AI Runtime**, the execution environments agents depend on.

## Engineering Philosophy

**Production over demos.** Prefer systems you can operate, harden, and evolve.

**Understand the architecture, not only the framework.** Retrieval, inference, sessions, tenancy, and failure paths need a clear model.

**Combine AI with reliable software engineering.** Auth, permissions, multi-tenant design, and system architecture are part of the product.

**Document what you learn.** This knowledge base keeps judgments, trade-offs, and open questions revisable.
